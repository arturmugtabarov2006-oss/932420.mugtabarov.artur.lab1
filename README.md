Автор: Мугтабаров Артур

Описание:
    Проект продолжает первые 5 лабораторных работ, начиная с 6 он разделён на 2 части - Пользовательскую -
        HTML-страница с информацией о навыках, соревнованиях и форме обратной связи.
    - Серверную - 
        Сервер написан но Node.js, с использованием Express. Он раздаёт статические файлы (HTML, CSS, JS, картинки) и обрабатывает API- запросы. 
        Реализован маршрут /api/random, который генерирует случайное число в заданном диапазоне.

Как запустить: 
    1. Загрузитьт проект, установить зависимости: npm install express.
    2. Запуск сервера: node server.js 
    3. Открыть в браузере  http://localhost:3000 
        (Подсказака отобразится в терминале)
    4. Для 3 варианта
        Проверка адресов
            http://localhost:3000/about
            http://localhost:3000/api/random
            http://localhost:3000/api/random?min=10&max=50 - API с параметрами 

Файлы
    Фрнт  
        - "index.html" - Главная страница сайта.
        - Папка Picture - все картинки.
        - "style.css" - Стили для отображения информации.
        - "about.html" - Страница с информацией
        - "script.js" - Общий функционал - переключение темы, добавление/удаление карточек.

    Сервер
        - "server.js" - фа1йл с основной логикой сервера (Точка входа)
        - "manifest.json" - файл для установки приложения
        - "service-worker.js" - отвечает за кеширование файлов        и работу оффлайн 

 - "README.md" - Описание проекта.
